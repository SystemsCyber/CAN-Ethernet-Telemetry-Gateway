## CAN-Ethernet Telemetry Gateway

This is a lightweight embedded application designed to demonstrate Software Bill of Materials (SBOM) generation, component visibility, and the identification of known vulnerabilities within a software package. The project highlights how dependencies in an embedded system can be enumerated, analyzed, and assessed for security risks using SBOM-based approaches.

This project consists of two main software components: an embedded Arduino C++ application running on the Teensy 4.1, and its associated third-party libraries. The firmware uses ArduinoJson to serialize telemetry messages into JSON format and mbed TLS to establish an encrypted communication session over Ethernet.

Both of these libraries have documented vulnerabilities associated with specific CVEs, making this project a practical example for demonstrating how SBOMs can be used to identify and analyze security risks within embedded software systems.
